# 5D DPM v0.15

Restore the permanent energy journey plot, reorganize the full set workflow without removing controls, enlarge the Camelot reference and explanations, add inline library designation editing, and introduce manual-only Bangers tags and filters. Existing profiles, analyses, training, sets, BPM corrections and exports remain available.

Mac: quit DPM, extract the ZIP, run Install.command. It backs up lightweight state and opens the native app. Confirm v0.15 at bottom left.
Windows 10/11 x64: extract the complete portable ZIP and open 5D DPM.exe. Keep _internal alongside it. Confirm v0.15-win-beta. WebView2 is required; this build is unsigned.

No separate rescan is required for this interface update. Bangers tags are separate from stage learning and are not copied when starting a fresh training profile.

See UI-AUDIT-v0.15.md for the audit, preserved capabilities, validation and real-device testing limits.
