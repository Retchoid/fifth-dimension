5D DPM Windows v0.12 beta

1. Extract the WHOLE ZIP, including the _internal folder.
2. Double-click 5D DPM.exe.
3. Confirm v0.12-win-beta at bottom left.
4. Scan a SMALL music folder first (MP3/WAV/FLAC/AIFF/OGG).
5. Test playback, seeking, BPM recheck, one category placement, and Sets & analysis.

No separate Python installation is needed. Microsoft Edge WebView2 Runtime is required.
Official WebView2 download if needed:
https://developer.microsoft.com/en-us/microsoft-edge/webview2/

This is an unsigned test build. Keep the executable with its _internal folder.
AAC/M4A codecs are not guaranteed. Serato crate installation is not available in this beta.

Data and launch.log: %LOCALAPPDATA%\5D DPM
No music files or tags are modified.
Report your Windows version, the app version, the failing action and launch.log if it fails.
