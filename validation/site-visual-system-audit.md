# 5th Dimension site-wide visual system audit

## Design standard

The site should feel like one recovered **late-1990s pirate-radio artefact**: heavy condensed type, deep charcoal/indigo substrate, cyan signal light, hot-magenta flyer ink, lime reward markers, and signal-orange accents. Boomboxes, tapes, dubplates, rave flyers, psychedelia, graffiti, and breakbeat culture should appear as physical details—screen-printed labels, cassette windows, speaker grilles, offset ink, scratched metal, scanlines, and dancefloor light—rather than generic website decoration.

The approved first hero remains unchanged. This audit covers everything from the audio portal onward and does not amend section names, written copy, media, or behavior.

| Site zone | Current thematic read | Audit outcome | Refinement direction |
|---|---|---|---|
| Navigation and hero | Pirate-radio masthead, city lights, graffiti mark, cyan/magenta identity, heavy display type. | Approved and protected. | No change. |
| Audio portal | Appropriate dual-deck framing but embeds need stronger physical DJ-hardware cues. | Consistent palette; missing tape/boombox material detail. | Add cassette-label strips, speaker-grille texture, and thicker hardware keylines around deck media. |
| Bio | Strong identity image and labels but is visually quieter than the hero. | Mostly coherent. | Add a restrained speaker-grid/ink edge so its portrait reads as part of the same sound-system world. |
| Mix archive | Existing covers and metadata are coherent after the dark framed treatment. | Solid pirate-radio identity. | Strengthen cassette-spine and dubplate-label details without altering any cover or copy. |
| Projects and performance matrix | Strong magenta/cyan framing but requires a shared flyer/photocopied texture. | Coherent but can be more tactile. | Add fixed-palette newsprint/dither overlay and cassette-style status rails. |
| Exclusive release and arcade entry | Cyan paint, record gate, and cabinet follow the brand. | Strongest post-hero bridge. | Preserve hierarchy; only align surrounding visual texture. |
| Visuals archive | Authentic supplied art is already the strongest psychedelic/graffiti element. | Approved. | Frame as a contact-sheet/record-sleeve wall while preserving art exactly. |
| Booking and contact | Uses the correct palette and signal language, but could better match the hardware/mixtape motif. | Needs tactile radio-console details. | Add mic-grid, tape-label, and transmitter-panel framing to form controls and contact buttons. |
| Footer | Correct core palette but currently reads as a plain terminus. | Needs integration. | Add compact tape-edge closure and printed-catalogue treatment. |

## Responsive finding

The desktop composition maintains a clear asymmetric transmission rhythm. The mobile composition retains the palette, visual hierarchy, and supplied art; however, post-hero modules need a more deliberate shared hardware/print texture to avoid feeling like separate card systems at narrow widths. The refinement pass will add only CSS framing, textures, and visual tokens—not content or functional changes.

## Post-refinement validation

Desktop and mobile full-page checks confirm the protected hero remains unchanged. From the audio portal onward, the shared hardware grammar now appears consistently in deck frames, archive modules, flyer/project treatments, the release-to-arcade bridge, visual contact sheet, booking console, contact transmitter modules, and footer. The required existing text, section names, artwork, media, interactions, game rules, and game copy remain intact. The completed build, TypeScript check, release gate verification, selector audit, and 17 unit tests provide regression evidence alongside the responsive visual checks.
