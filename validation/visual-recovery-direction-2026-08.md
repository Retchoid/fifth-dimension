# Visual Recovery Direction — August 2026

The user specified that this work is a **visual recovery pass**, not a redesign. The existing illustrated event screens—especially **Cops Seized Your Mixer**, **Too High To Play**, and their graffiti/comic police-vinyl compositions—are the canonical art direction for active gameplay.

The working constraints are: retain game mechanics and smooth performance; use only existing project artwork; avoid generic clip art, emoji, colour blocks, and generated substitutes; make the player, pickups, and hazards visually readable on mobile; preserve the cabinet; reduce HUD dominance; and keep active play visually continuous with the illustrated event scenes without repeating the same full event art across the playfield.

The required audit covers all stored assets, source references, orphaned assets, broken routes, historic references, Jersh’s yellow-block root cause, floating homepage text, header-player placement, and six mobile viewports. Acceptance requires visual evidence at 390×844 for active play, Cops, Too High, the homepage, and the Jersh section, alongside a documented asset/path/cause report and confirmation that collision/gameplay logic and performance safeguards remain unchanged.
